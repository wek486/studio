拾光 Studio 2.0 · Windows 本地图片工作台

运行：双击 Shiguang-Studio-2.0.1-Windows.exe，等待数秒解包后进入工作台。
ZIP版：完整解压 Shiguang-Studio-2.0.1-Windows.zip，再双击“拾光 Studio.exe”。请保留其旁边全部运行时文件。
无需另外安装 Python 或 Node.js，本地功能不需要 API 密钥。

开始使用
1. 导入照片，或在工作台点击“试用示例照片”。
2. 左侧选择调整、人像、抠图、画笔、文字贴纸、拼图、批处理或工具箱。
3. 调色/滤镜先预览，再点击应用。画笔先显示涂画标记，点击应用才改变实际图片。
4. 每一步可撤销和重做，底部历史缩略图可返回已有版本。
5. 导出当前照片用于分享；保存 .sgproj 项目可下次恢复编辑历史。

人像与塑形
随包YuNet离线模型提供人脸检测，只辅助框选，不等同精确五官重塑。局部美白、祛痘、去油光、亮眼、美牙、黑眼圈和染色，请先框选实际部位，再调强度并应用。塑形提供手动推移和局部纵向伸缩，需检查背景是否变形。这些工具不等于原版自动五官或美颜模型。

抠图与背景
人物照片可直接选择“离线人像抠图”，使用随包PPHumanSeg模型，无需联网。普通物体可框住完整主体后选“框选通用主体”。提取透明主体后，再到边缘修补涂画保留或去除区域。低分辨率人像分割不保证精细发丝。可直接擦除、恢复原图、反选透明区域或羽化。保留区域用绿色标记，去除区域用红色标记。点击应用后生效。换纯色、渐变或图片背景前需先得到透明主体。

画笔、文字和水印
涂鸦、修复、马赛克、透明擦除均可直接在照片上画。清除标记不会修改图片。文字、星形/爱心等图形和导入图片贴纸可放在框选区域；无选区时放在中心。批处理也支持文字水印。

拼图与证件照
拼图支持网格、保持原比例的长图/横拼、四种海报和自动错落排版。按输入列表顺序排列，填满单元可能裁边，可选保留完整图片。
证件照先抠图再选规格与底色，打印排版可用六寸或A4并显示裁切标记。PNG/JPEG写入300DPI。常用规格不保证官方审核通过，请核对实际用途要求。

批量处理
选择多张照片，设置最长边、格式、质量、调色或水印，可勾选离线人像抠图，再选择输出文件夹。抠图后要保留透明背景，请输出PNG；JPEG会合成白底。程序新建结果子文件夹，不覆盖原图，显示逐张进度并记录失败原因。取消保留此前已完成文件。

本地工具箱
文字识别由Windows系统OCR完成，识别结果可校对、复制、导出Word/表格。OCR语言取决于系统已安装组件；本机验证的是简体中文。Word/表格提供文字与基础排版，不自动恢复原文档复杂版式。
也可使用图片转PDF、PDF按页转PNG、GIF制作、九宫格切片、格式转换与压缩。PDF导图使用Windows本地组件。

画布与快捷键
空格按住拖动：平移；Ctrl+滚轮：缩放。
Ctrl+O 导入；Ctrl+V 粘贴图片；Ctrl+S 导出图片；Ctrl+Shift+S 保存项目。
Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+Shift+C 复制当前图片；Esc 清除选区和标记。
切换工具前请应用要保留的画笔效果。

保存与限制
单张图片最多3200万像素。项目最多保存30个历史版本，图像数据总量最多128MB，不包含独立图层、未应用画笔或全部输入队列。较长历史保留原图和当前活动附近版本，重要原图请自行保留。
PNG保留透明，JPEG合成白底。原始导入文件只读，处理后另存新文件。图片导出不等于保存了可恢复的项目历史。

尚未复现的能力
原版高精度自动五官与发丝模型、原版美颜模型、原商业素材、会员账号、云端生成和修复、AI商品图/换装/写真、视频编辑及视频去水印不在此版本内。手动工具或传统图像处理不宣称与原版自动模型等价。

鼠标交互更新（2.0.1）：画布直接使用滚轮缩放，以鼠标位置为中心；默认左键拖动画面，任意工具下右键或中键也可拖动。画布上方可直接切换“拖拽 / 框选 / 画笔”。画笔默认松手后应用并可撤销；取消“松手应用”可先标记再点击右侧应用。放大后涂画保留当前视野；拖拽模式下双击画布复位。
